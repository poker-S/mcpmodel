# ADR-0006：校准角色隔离与硬规则决策边界

- 状态：Accepted
- 日期：2026-08-12

## 背景

风险概率、概率校准、Conformal 风险集合与治理动作属于不同统计和安全层。若使用同一验证
样本同时拟合温度和 Conformal 分位数，或根据测试结果选择阈值，会低估不确定性。若统计
模型可以直接产生自动拒绝，则小样本过拟合可能破坏正常任务。

## 决策

1. 训练、概率校准、Conformal 校准和测试按 `scenario_group` 互斥；测试只评估一次固定流水线。
2. 温度缩放只拟合概率校准角色；Conformal 分位数只拟合独立的校准角色。
3. 统计风险集合可以自动放行低风险调用或升级人工审批，但不能独立触发自动拒绝。
4. `deny` 只来自版本化的不可变硬规则；`rewrite/isolate` 只来自显式声明的安全降级规则。
5. 样本量不足、温度触边或预测集退化必须进入机器可读限制项，并禁止正式研究使用。

## 后果

小规模 Pilot 上的预测集可能非常保守，审批率可能很高；这是可信的不确定性表达。正式数据
到位后可以在不改变接口和安全边界的情况下替换拟合数据并重新冻结配置。
