# ADR-0002：按场景组切分并冻结正式测试集

- 状态：Accepted
- 日期：2026-08-12

## 背景

模板化合成样本可能只在实体名、路径和参数上变化。随机逐条切分会让同一模板或同一攻击链的近重复样本同时进入训练集和测试集，造成明显的指标虚高。

## 决策

1. 以 `scenario_group` 为最小切分单元，同组样本不得跨集合。
2. 对文本规范化后计算近重复指纹，切分后再次检查泄漏。
3. 外部迁移集与正式测试集一旦冻结，只允许修正经双人确认的客观标签错误。
4. 调参只使用训练集和验证集；正式测试指标只生成一次主报告。
5. 每次切分记录随机种子、输入数据哈希、组数、类别分布和生成脚本版本。

## 后果

可用训练样本会减少，置信区间可能变宽，但结果更接近对新任务、新工具和新攻击链的真实泛化能力。
