# ADR-0005：风险标注前执行任务盲法授权重建

- 状态：Accepted
- 日期：2026-08-12

## 决策

缺失授权的外部 Agent 轨迹不得直接进入风险标注。先按 `scenario_group` 由两名复核员仅依据原始用户任务独立重建授权；完全一致则冻结，不一致由第三人裁决。观察到的调用只能生成非权威机器草案，不能倒推出授权。

## 原因

项目的核心特征是调用与授权之间的偏差。如果把实际调用直接复制为授权，将系统性地把越权调用改写为合规调用，形成标签泄漏并消除研究对象。若完全放弃真实轨迹，又会损失有价值的真实调用链。分阶段双人复核在保留轨迹的同时，明确分离观察事实与规范性边界。

## 后果

进入风险盲标前增加人工成本；授权不足的场景会被排除；但每个授权字段都有证据基础，任务哈希可防止复核后上下文漂移，论文可以报告授权重建一致性与排除率。
