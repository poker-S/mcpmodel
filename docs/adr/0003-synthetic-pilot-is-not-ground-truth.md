# ADR-0003：合成 Pilot 只用于工程验证，不作为独立真值

- 状态：Accepted
- 日期：2026-08-12

## 背景

项目需要先验证 Schema、特征、规则、分组切分和训练脚本能否闭环运行。直接等待正式人工标注会阻塞工程风险暴露；但如果用规则或场景设计标签训练后再将结果写成模型有效性证据，会形成标签循环。

## 决策

1. `pilot-0.1` 的 30 条标签明确记为 `scenario_design_not_human_adjudicated`。
2. 它只验收数据和训练流水线，不用于论文性能结论、超参数选择或安全声明。
3. 任何基线报告必须显示 `pipeline_smoke_test_not_independent_evidence`。
4. P1 的研究性退出条件仍需三名标注者独立试标并保留原始答案。
5. 合成试标集中的测试划分不是未来正式测试集，可在人工标注前重建。

## 后果

可以尽早发现工程和特征缺陷，同时避免把自定义规则的复现能力误报为模型泛化能力。
