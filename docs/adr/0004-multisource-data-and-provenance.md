# ADR-0004：多源数据全部接入，但按证据角色隔离

- 状态：Accepted
- 日期：2026-08-12

## 决策

长亭五类样例全部进入数据流水线，但不强行归一为同一种监督标签：轨迹/部署是待人工标注候选，Prompt 是辅助语料，CVE 是场景种子，AI-VULNATLAS 是外部评测。每条记录必须保存来源、文件哈希、定位器、转换版本、允许用途和标签状态。

## 原因

它们的观测单位和标签语义不同。把 `unsafe`、CVSS、验证成功或漏洞类型直接映射到 L0～L4，会引入伪真值和标签循环；完全不用又会浪费真实调用链、正常部署和攻击证据。

## 后果

训练前多一步授权重建和人工标注，但所有数据都能在适合的角色中发挥作用，且论文可准确说明来源、限制和血缘。
