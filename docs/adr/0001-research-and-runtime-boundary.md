# ADR-0001：研究模型与运行时执行边界

- 状态：Accepted
- 日期：2026-08-12

## 背景

完整 MCP 治理系统涉及模型、策略、隔离、凭据、审计和恢复。当前资源为 2 vCPU / 4 GiB，论文首要任务是建立有效且可复现的风险决策闭环。

## 决策

第一阶段以离线 JSON/YAML 调用记录为输入，完成规范化、授权偏差、风险模型、校准集合、决策解释和指标。端到端运行时只实现 filesystem、shell、git 和 mock HTTP，并禁止连接生产系统。

## 结果

优点：范围可控、实验可复现、适合当前算力。代价：论文对真实生产性能和复杂隔离只做有限声明，必须在局限性中说明。
